HOW IT WORKS

The simulator builds a pool of modifiers from both parent items, randomly selects which modifiers survive, then enforces item prefix/suffix limits and modifier-group exclusivity.

The simulation engine is deliberately separated from the interface so the recombination model can be replaced with league-specific mechanics later.
